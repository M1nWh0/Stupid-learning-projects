# Stupid Learning Projects

This repository contains three independent SvelteKit demo applications used for learning and prototyping:

1. **Multi-page SvelteKit Application** – Demonstrates routing, layout, and basic page components.
2. **User Management CRUD** – A simple CRUD interface for managing user data with a mock backend.
3. **HTTP API Consumption** – Shows how to fetch data from external APIs and display it in a SvelteKit app.

Each project resides in its own numbered folder and can be developed separately.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/M1nWh0/Stupid-learning-projects.git
cd "Stupid-learning-projects"
```

Pick a project, install its dependencies, and launch the development server:

```bash
cd "1.Multi-page SvelteKit Application"  # or 2.User Management CRUD, 3.HTTP API Consumption
npm install   # or pnpm install if a pnpm-lock.yaml is present
npm run dev
```

The app will be available at `http://localhost:5173` (or the port shown in the console).
